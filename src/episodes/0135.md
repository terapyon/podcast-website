# #126 池内さんをゲストに 手書きコードの消滅から「ソフトウェアファクトリー」、LanceDB・S3 Vectorsまで

# Note

<p>準レギュラーゲストの池内さんをお迎えし、AIコーディングが当たり前になった現在（2026年時点）の開発環境や、サプライチェーン攻撃へのリアルな危機感、人間をボトルネックにしない「ソフトウェアファクトリー」の仕組み、さらにはLanceDBやAWS S3 Vectorsなどの検索技術・小冊子執筆の近況まで、たっぷり語り合いました。 </p><p><br /></p><p><strong>タイムスタンプ（チャプター）</strong></p><ul><li><strong>00:00</strong> オープニング・AIの進化スピードと近況</li><li><strong>03:45</strong> 手書きコードの消滅と、エディタ選び（VS CodeをアンインストールしてZedへ移行した話）</li><li><strong>11:15</strong> AI時代のセキュリティ危機感と技術スタック選定（Bun / npmまわりのリスク）</li><li><strong>17:40</strong> AIボット・エージェント活用（Grok Bots、Devin Bots、Dotsなどの使い分け）</li><li><strong>28:40</strong> 「ソフトウェアファクトリー」と人間がボトルネックにならない仕組みづくり</li><li><strong>41:15</strong> イベント告知：12月12日開催「PyCon mini Tokyo with Python Asia Conference」</li><li><strong>46:30</strong> LanceDBと検索技術（S3バックエンド運用、日本語全文検索・BM25・ハイブリッド検索、AWS S3 Vectors）</li><li><strong>1:11:30</strong> 小冊子執筆の近況（ベクトル検索とWebセキュリティの解説本制作）</li><li><strong>1:27:00</strong> エンディング</li></ul><p><br /></p><p>1. 手書きコードの消滅とエディタ選び（VS Code → Zed）</p><ul><li><strong>登場キーワード</strong>：Zed、VS Code、Claude（Anthropic）、OpenAI、Gemini、Cursor（Anysphere）、Rust</li><li><strong>話したこと・感想</strong>：</li><ul><li>自分でゼロからコードを手書きする機会がほとんどなくなり、AIへの指示出しや出力のレビューがメインになったことで、従来のIDEに求める役割が大きく変わったという実感。</li><li>拡張機能で重くなりがちな <strong>VS Code</strong> を思い切ってアンインストールし、Rust製の爆速エディタ <strong>Zed</strong> へ移行した体験談。「コードを書く場所」ではなく「確認・閲覧するビューア」として使うなら軽快さが正義という結論に。</li><li><strong>Anthropic（Claude）</strong> や <strong>OpenAI</strong>、<strong>Gemini</strong>、<strong>Cursor（Anysphere）</strong> など、日々のタスクに応じたモデル・ツールの使い分け事情。</li></ul></ul><p><br /></p><p>2. AI時代のセキュリティ危機感と技術スタック選定</p><ul><li><strong>登場キーワード</strong>：Bun、npm、サプライチェーン攻撃、依存パッケージ</li><li><strong>話したこと・感想</strong>：</li><ul><li>AIがものすごいスピードでコードを生成し、パッケージを次々と導入できるようになったからこそ、「知らないうちに悪意ある依存パッケージを踏み抜く（サプライチェーン攻撃）リスクが跳ね上がっている」という強い危機感。</li><li><strong>Bun</strong> のようなモダンなランタイム・ツールチェーンを採用する際の快適さと、セキュリティや枯れ具合・安定性をどう天秤にかけるかという技術選定の本音。</li></ul></ul><p><br /></p><p>3. AIボット・エージェント活用のリアル</p><ul><li><strong>登場キーワード</strong>：Grok Bots、Devin Bots、Dots、Slack / チャット連携</li><li><strong>話したこと・感想</strong>：</li><ul><li><strong>Grok Bots</strong>、<strong>Devin Bots</strong>、<strong>Dots</strong> など、自律的に動いてタスクをこなしてくれる各種AIボット・エージェントの比較と、それぞれの得意領域。</li><li>エンジニアリング領域だけでなく、日々のタスク管理や事務手続きなどの「バックオフィス業務」にAIボットを組み込んで自動化していく手応えと面白さ。</li></ul></ul><p><br /></p><p>4. 「ソフトウェアファクトリー」と人間がボトルネックにならない仕組み</p><ul><li><strong>登場キーワード</strong>：ソフトウェアファクトリー（Software Factory）、ライトファクトリー / ダークファクトリー（Dark Factory）、CI/CD、自動テスト</li><li><strong>話したこと・感想</strong>：</li><ul><li>工場の無人自動化（消灯工場＝ダークファクトリー）になぞらえ、要件定義から実装・テスト・デプロイまでをAIパイプラインで一気通貫させる「ソフトウェアファクトリー」の概念について。</li><li>AIの実装スピードが人間の処理能力を完全に追い越した今、「人間のレビュー待ちや意思決定こそが一番のボトルネックになる」という気づきと、人間がボトルネックにならないための仕組みづくり・マインドセットの転換。</li></ul></ul><p><br /></p><p>5. イベント告知：PyCon mini Tokyo with Python Asia Conference</p><ul><li><strong>登場キーワード</strong>：PyCon mini Tokyo with Python Asia Conference、Python</li><li><strong>話したこと・感想</strong>：</li><ul><li>12月12日に開催される <strong>「PyCon mini Tokyo with Python Asia Conference」</strong> の告知。アジア圏のPythonコミュニティともつながる貴重な機会としての見どころを紹介。</li></ul></ul><p><br /></p><p>6. LanceDBと検索技術の最新動向</p><ul><li><strong>登場キーワード</strong>：LanceDB、AWS S3、AWS S3 Vectors、ベクトル検索、全文検索、BM25、ハイブリッド検索</li><li><strong>話したこと・感想</strong>：</li><ul><li>オブジェクトストレージ（<strong>AWS S3</strong>）をバックエンドにしてサーバーレスかつ低コストに運用できる <strong>LanceDB</strong> の使い勝手とアーキテクチャの魅力。</li><li>ベクトル検索だけでは取りこぼす固有名詞やキーワードを補うために、従来の全文検索（<strong>BM25</strong>）を組み合わせた「ハイブリッド検索」と日本語処理の重要性。</li><li>ストレージ自体にベクトル検索機能が統合される <strong>AWS S3 Vectors</strong> のような動きがもたらす、インフラ構成のシンプル化への期待。</li></ul></ul><p><br /></p><p>7. 小冊子執筆の近況（ベクトル検索＆Webセキュリティ）</p><ul><li><strong>登場キーワード</strong>：ベクトル検索、Webセキュリティ、技術書・小冊子執筆</li><li><strong>話したこと・感想</strong>：</li><ul><li>イベント頒布やアウトプットに向けて執筆を進めている「ベクトル検索」と「Webセキュリティ」の解説小冊子の進捗報告。AI時代だからこそ基礎となる検索アルゴリズムやセキュリティの知識を体系化して残す意義について。</li></ul></ul><p><br /></p><p>Links:</p><ul><li><strong>エディタ</strong>：<a href="https://zed.dev/" rel="noreferrer nofollow noopener" target="_blank">Zed</a></li><li><strong>ランタイム</strong>：<a href="https://bun.sh/" rel="noreferrer nofollow noopener" target="_blank">Bun</a></li><li><strong>イベント</strong>：<a href="https://mini-tokyo.pycon.jp/ja/" rel="noopener noreferer" target="_blank">PyCon mini Tokyo with Python Asia Conference（12月12日開催）</a></li><li><strong>検索・データベース</strong>：<a href="https://lancedb.com/" rel="noreferrer nofollow noopener" target="_blank">LanceDB</a></li></ul>
