# Note

<p><strong>Summary:</strong></p><p>検索・AIエンジニアの打田さん（<a href="https://bsky.app/profile/mocobeta.dev" rel="noreferrer nofollow noopener" target="_blank">@mocobeta</a>）をゲストに迎え、検索とAI技術の深遠な世界を語り合いました。寺田氏のPyCon JP登壇内容（VLM・顔認識による写真検索システムの無料枠構築）や、打田氏の「Encraft（エンクラフト）＃25」登壇資料を軸に、バイエンコーダー構造、ANNアルゴリズム、RAGにおけるセルフチェックやハイブリッド検索の重要性、さらにLanceDBの革新性やApache Luceneでの開発裏話まで深掘り。</p><p><br /></p><p><strong>Guest:</strong></p><p>打田さん（@mocobeta）<a href="https://bsky.app/profile/mocobeta.dev" rel="noreferrer nofollow noopener" target="_blank">https://bsky.app/profile/mocobeta.dev</a></p><ul><li>AIエンジニアをしています。AIアプリケーションで検索技術を活かすことに興味があります。</li><li>GitHubやSNSでは mocobeta というハンドルネームを使っています。</li><li>オープンソースが好きで，個人ではJanomeという形態素解析ライブラリを作っていたり（懐かしいという方も多いかもしれません），OSS検索ライブラリのApache Luceneの開発にコミッターとして関わっていたりしました。</li><li>ラムダノートさんから2022年に「検索システム　実務者のための開発改善ガイドブック」という本を出させていただきました。</li></ul><p><br /></p><p><strong>Contents:</strong></p><ul><li>ゲストの打田さん（<a href="https://bsky.app/profile/mocobeta.dev" rel="noreferrer nofollow noopener" target="_blank">mocobeta</a>）の自己紹介とバックグラウンド</li><li>形態素解析ライブラリ「<a href="https://mocobeta.github.io/janome/"
